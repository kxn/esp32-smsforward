# 来电号码标记查询

转发来电通知时，如果能顺带说明这个号码"是谁"，会比只显示号码更有用。号码归属地
和常用客服号是离线查表的（见 `PHONE_ORIGIN_DATA.md`），但"骚扰电话""快递送餐"这类
标记只在第三方数据库里，必须联网查询。

这个功能**默认关闭**，只在用户填了服务地址后生效，而且只查来电，不查短信：短信一看
内容就知道是什么，来电不接则完全无从判断。

## 行为

- 触发条件：`feishu_configured()` 为真、飞书没有处于连续失败退避中、来电号码可以拨号
  （`cmd_policy_dial_number()`），且本地离线表**没有**把这个号码识别成已知机构
  （已知银行客服等不再浪费查询额度）。
- 查询预算：默认 2000 ms，可在设备上配成 500–5000 ms。超时、HTTP 非 200、连不上、
  没有配置地址或密钥，都**按原样发送不带标记的通知**，不会因为查询失败而丢通知。
- 结果拼在归属地后面：`（北京 · 快递送餐）`；本地表查不到归属地时只显示标记：
  `（骚扰电话）`。
- 缓存：32 条。命中过的号码缓存 24 小时，"查过但没有标记"的缓存 6 小时（这样今天被
  标记的号码明天还能查出来）。改服务地址或密钥即清空缓存。
- 纯内存缓存，不写 Flash；计数器在重启后归零。

## 服务地址模板

设备按模板拼出 GET 请求：

```
https://apis.juhe.cn/mobileVerify/query?key={key}&phone={number}
```

- `{number}` 会被替换成主叫号码的纯数字形式（去掉 `+`、空格、括号、连字符；带 `+86`/`0086`/`86` 国家码的会去掉 `86`，这样国内号码无论运营商怎么写都查同一个键）。
- `{key}` 会被替换成配置的密钥。
- 模板必须以 `http://` 或 `https://` 开头，必须包含 `{number}`，长度上限 191 字节。
- 响应最多读 2048 字节，只接受 HTTP 200。

## 响应解析

容错扫描，不要求固定结构，按优先级收集标签：

1. `tags` 数组里的 `{"name": "...", "count": n}`；
2. 键 `tag` / `mark` / `label` / `category` 的字符串值；
3. `catnames` / `catname`：按 `,` `，` `/` 拆分；
4. `tags: ["骚扰", "诈骗"]` 这样的字符串数组；
5. `fid` 数字（聚合数据「来电号码显示」语义）：

   | fid | 标签 |
   | --- | --- |
   | 1 | 骚扰电话 |
   | 2 | 推销 |
   | 3 | 中介 |
   | 4 | 快递送餐 |
   | 5 | 疑似诈骗 |
   | 6 | 招聘猎头 |
   | 7 | 出租车司机 |

`未标记`、`无标记`、`正常`、`normal`、`unknown` 这类占位值会被忽略。最多取两个标签，
用 `/` 连接；超过 47 字节的标签整条丢弃，不做截断（不会切坏 UTF-8）。

## 服务商

| 服务商 | 接口 | 说明 |
| --- | --- | --- |
| 聚合数据 | `https://apis.juhe.cn/mobileVerify/query` | 返回 `flag.fid` 与 `catnames`，单次调用即可拿到分类；需注册 AppKey，有免费试用额度，之后按次计费 |
| Tmini | `https://api.tmini.net/apis/checkmark` | 聚合腾讯/360/百度/小米等平台，300 积分/次，需充值 |
| 各类"免 key 聚合" | — | 2025 年实测已全部改为强制 `ckey` 并要求登录，且注册关闭，不再可用 |

模板是通用的，换服务商只要改地址（以及必要时在 `peer_mark_core.c` 里补标签映射）。

## 配置方式

- 局域网管理页「号码标记」：填查询地址、密钥、超时，保存后立即生效。
- 串口控制台：`mark` 打印当前配置与统计（只读）。
- RPC：`{"cmd":"mark_set","url":"...","key":"...","timeout_ms":2000}`；`url` 传空串即关闭，
  省略 `key` 表示保留原密钥。错误码：`url`（模板不合格）、`key`（密钥过长）、
  `save_failed`。
- 诊断：`status` 里的 `mark` 对象：`enabled`、`url`、`timeout_ms`、`queries`、`timeouts`、
  `failures`、`cache`、`last_ms`、`last_label`。密钥不会回显。

## 隐私与代价

- 主叫号码会被发送给你配置的第三方服务商，请自行判断是否接受。
- 每次查询占用一次来电通知的转发时间（最多就是超时预算），并且消耗服务商额度；
  本地表能识别的号码不查，查询结果会缓存，所以实际消耗很小。
- 密钥以明文存于设备 NVS，不会通过状态接口回显；局域网管理页使用 HTTP，请只在可信
  局域网内使用。
